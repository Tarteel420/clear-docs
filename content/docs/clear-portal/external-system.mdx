Connecting an **external system** lets you pick vendors and purchase orders from that system instead of typing them in. Until one is connected, vendor profiles fall back to manual entry.

## Connecting an external system

<Steps>
<Step>Click **External System** under **Configuration** in the portal menu. If nothing is connected, the page shows **No external system connected**.</Step>
<Step>Click **Connect external system** (top right). The Connect external system dialog opens.</Step>
<Step>
Open the **Provider** list and choose **AccountWise**.

![Connect external system dialog](/docs-images/clear-portal/connect-external-system.png)
</Step>
</Steps>

## Disconnecting

To disconnect, open the **Connect external system** dialog and choose **NoProvider (disconnect)** from the **Provider** list.
