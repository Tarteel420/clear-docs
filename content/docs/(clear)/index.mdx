## What is Clear?

Clear is a secure data sanitization solution designed to perform controlled, auditable erasure of storage devices in enterprise and IT Asset Disposition (ITAD) environments.

Clear enables organizations to securely wipe HDDs, SSDs, and NVMe drives using industry-aligned erasure methods, while maintaining full operational traceability, job-level control, and report generation.

Clear is deployed as a desktop application and automatically detects connected storage devices at launch. It provides detailed device metadata, SMART health analysis, wiping configuration controls, and real-time progress monitoring.

Clear is built for organizations that:

- Process refurbished storage devices
- Operate IT asset disposition (ITAD) workflows
- Require structured, job-based erasure management
- Need downloadable, device-level certificates and CSV reports
- Maintain audit trails for compliance and internal governance
